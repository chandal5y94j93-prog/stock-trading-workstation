# 个人交易纪律手册

> 适用账户：同花顺模拟炒股（`模拟炒股*gutz`）
> 版本：v1.0（2026-08-07）
> 性质：自我约束工具，不构成投资建议

## 一、总目标

1. 用模拟盘验证自己的交易逻辑，先跑通「计划 → 执行 → 复盘 → 修正」的闭环。
2. 把亏钱的主要原因限制在「判断错误」，而不是「纪律失控」。
3. 单次模拟交易只承担可承受的损失，任何一笔交易都不能影响账户整体存活。

## 二、核心原则

1. 没有计划的交易不做；计划外的追涨杀跌一律视为违规。
2. 单只股票仓位不超过总资金 20%；总仓位不超过 80%。
3. 单日新建仓不超过 40%，单日止损金额不超过总资金 5%。
4. 买入必须分批：至少分 2 笔，第一笔不超过计划仓位的 50%。
5. 止损无条件执行：单笔亏损达到 8%，或跌破计划止损位，直接卖出，不找理由。
6. 止盈同样机械执行：达到目标价减半仓，其余按移动止盈处理。
7. 不加仓摊平亏损；亏损仓只在计划内减仓。
8. 不在大涨 7% 以上且 KDJ J 值大于 100 时追高。
9. 每天只允许在固定时段查看行情，禁止盘中情绪化决策。
10. 每天收盘后必须完成复盘记录，不完成复盘不建新仓。

## 三、买入纪律（全部满足才买入）

| 条件 | 要求 | 说明 |
| --- | --- | --- |
| 趋势 | 站上 MA20，或修复形态确认 | 不接下跌中的飞刀 |
| 资金 | 当日主力净流入为正 | 与散户反向 |
| 位置 | 不在单日涨幅 > 7% 时追高 | 等回踩 |
| 量能 | 放量突破或缩量回踩关键位 | 两种买点 |
| 计划 | 提前写好买入价、止损价、目标价 | 盘中只执行 |
| 风险 | 单票仓位 ≤ 20%，总仓位 ≤ 80% | 先算仓位再下单 |

买入流程：

1. 收盘后选股，写入明日计划。
2. 次日只在计划价格区间执行。
3. 第一笔 50%，确认走势后第二笔 50%。
4. 成交后 30 秒内记录成交价与理由。

## 四、卖出纪律

| 情形 | 动作 |
| --- | --- |
| 亏损达 -8% | 无条件清仓 |
| 跌破关键支撑（如 MA20 或计划止损位） | 无条件减仓或清仓 |
| 盈利达 +15% | 减半仓，剩余持仓设保本价 |
| 盈利回撤超过最高点 8% | 移动止盈触发，清仓 |
| 买入理由消失（趋势/资金/逻辑变化） | 主动离场，不依赖价格 |
| 尾盘放量跌破分时均价 | 次日开盘确认后处理 |

## 五、每日流程

### 盘前（交易日 08:50 - 09:15，15 分钟）

- 检查隔夜消息与大盘状态。
- 核对自选股前一日收盘形态、支撑压力。
- 写下今日计划：观察清单、触发条件、止损止盈。
- 不设计划的票，今天不碰。

### 盘中（09:30 / 11:00 / 14:00 三档）

- 只在计划触发时下单。
- 每档只看 5 分钟，其余时间不盯盘。
- 盘中不修改计划；确实需要修改，先关掉行情想清楚再决定。

### 盘后（15:10 - 15:40，20 分钟）

- 记录当日成交、持仓、盈亏。
- 对照计划逐笔打钩：是否按计划执行、情绪是否失控。
- 写下明日关注点与计划。
- 未完成复盘，次日不允许新开仓。

## 六、复盘模板

| 项目 | 内容 |
| --- | --- |
| 日期 / 市场 | 2026-08-07 / 上证 +1.02% |
| 今日操作 | 买卖什么、价格、数量 |
| 是否符合计划 | 是 / 否，偏差原因 |
| 最大错误 | 追高、扛单、频繁交易、仓位失控 |
| 情绪状态 | 冷静 / 焦虑 / 贪婪 / 恐惧 |
| 明日计划 | 观察标的、触发条件、仓位 |
| 纪律评分 | 0 - 100 |

## 七、禁止清单

- 禁止盘中去打听消息后临时改主意。
- 禁止用「再等等」替代止损。
- 禁止亏损后立刻重仓回本。
- 禁止一天内交易超过 3 个标的。
- 禁止同时持有超过 5 只股票（ETF 和指数不算）。
- 禁止用模拟盘验证没有逻辑的赌博式操作。

## 八、违规处理

- 每违反一条纪律，记录一次；一周内违规超过 3 次，暂停模拟交易 2 天。
- 连续两次同一类违规，降低单票仓位上限 5 个百分点。
- 连续 4 周纪律评分低于 70，暂停交易并重读本手册。

## 九、风险声明

模拟盘用于训练纪律与流程，不代表真实收益。任何技术指标和 AI 解读都有失效的可能，最终决策和后果由本人承担。
